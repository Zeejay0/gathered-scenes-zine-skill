# Text Material Guide

Use text as one short readable unit with a spatial behavior, not as an isolated caption. Keep its wording exact when supplied; otherwise follow the main skill's language and length rules.

## Choose One Primary Behavior

- **Semantic break:** separate a phrase at a word boundary or separator to create a pause. Use when the image already contains a split, seam, step, or threshold.
- **Drifting baseline:** let fragments rise, fall, or lightly arc along a source movement. Use for wind, water, walking, branches, gestures, or soft terrain.
- **Offset / misregistration:** shift one small echo slightly from the main imprint. Use for photocopy, risograph, memory, reflection, or unstable weather; keep the wording readable.
- **Two-scale contrast:** let one word or fragment carry the larger physical weight while another becomes a small response. Use for a clear subject–atmosphere relationship.
- **Directional alignment:** run type along a horizon, rail, gaze, arm, road, stair, chair angle, or shadow. Use a direction that explains the text's placement.
- **Selective occlusion:** let one image edge or color passage cross part of a text fragment. Use only when the reading order stays obvious.

Use one behavior by default. Combine at most two only when they come from the same source gesture; for example, a drifting baseline with a modest scale change along a shoreline.

## Set the Reading Order

- Make the intended read order obvious through proximity, value, scale, or a consistent directional path.
- Keep all words fully spelled and all Chinese characters complete enough to identify. Never replace readability with visual cleverness.
- Break phrases at semantic pauses. Do not scatter individual letters across unrelated parts of the poster.
- If text is partially covered, leave distinctive letter features visible and avoid covering the beginning and end of the same word.

## Build Type Voices

- Use one type voice for a one-piece unit; use two only for a primary fragment plus a smaller echo.
- Pair voices with a reason: typewriter + faint pencil, dry ink + monospaced print, or restrained Song-style print + small mechanical English.
- Keep ink values in one paper-derived family. Slight offset or broken pressure is enough to establish material difference.
- Avoid polished display typography, three or more fonts, bold advertising hierarchy, decorative title cases, or random size changes.

## Place the Unit in the Composition

- Let type attach to an image edge, enter a quiet field, pass behind a subject, or emerge from an illustration—not merely sit beneath the image.
- Keep the primary subject visually dominant. Text can touch or overlap the subject, but it may not conceal a face or destroy the scene's semantic minimum.
- Use blank paper as part of the textual rhythm. A break, gap, or drift must create breathing room rather than clutter.
- At thumbnail size, the text should read as a deliberate material event; at normal size, every word must be readable.

## Correction Checks

- If text feels like a conventional caption, attach its baseline, break, or overlap to a real source gesture.
- If text feels chaotic, reduce it to one behavior, two type voices maximum, and one clear reading order.
- If text is too dominant, reduce the large fragment or lower its contrast before shrinking all text uniformly.
- If text is illegible, restore the complete wording first, then retain only the material variation that does not hinder reading.
